# 🐍 OOP in Python — Classes & Objects

> **the foundation of OOP** · part of a hands-on **Python Object-Oriented Programming** learning series.

## Concept

Defines a class as a **blueprint**, then creates objects (instances) from it and reads their attributes. Shows how `Student` and `Car` classes produce independent objects.

## Run it

```bash
python Oops1.py
```

This repo is one lesson in a step-by-step OOP journey — from classes & objects through constructors, encapsulation, inheritance, `super()`, and decorators like `@classmethod` and `@property`. Browse the other `Oop*` repos on my profile to follow the full path.
